# Ionic Day 1 Starter Project

## Project Overview
This project is created as part of the 20-Day Ionic App Development Training Program.

## Technologies Used
- Ionic Framework
- Angular
- TypeScript
- Capacitor
- Node.js
- npm

## How to Run the Project

1. Install dependencies:

   npm install

2. Start the development server:

   ionic serve

3. Open the URL displayed in the terminal.

## Tasks Completed
- Created Ionic Angular starter project.
- Installed Capacitor CLI.
- Configured Capacitor.
- Installed Capacitor plugins.
- Successfully ran the application in browser.

## Learning Outcome
Learned the basics of Ionic, Angular, Capacitor and project setup.
