# Ionic Day 3 – Angular Services and Dependency Injection

## Project Overview
This project is developed as part of the 20-Day Ionic App Development Training Program.

Day 3 focuses on separating application logic from the user interface using Angular Services and Dependency Injection.

## Technologies Used
- Ionic Framework
- Angular
- TypeScript
- RxJS
- Node.js
- npm

## Topics Learned
- Angular Services
- Dependency Injection
- TypeScript Interfaces and Typed Models
- Mock Data Management
- Task Filtering
- Observable Basics

## Practical Implementation
- Created a Task interface.
- Created an Angular TaskService.
- Implemented Dependency Injection in HomePage.
- Moved mock task data into TaskService.
- Implemented All, Pending and Completed task filters.
- Connected TaskService with the Home page.
- Tested task addition and task filtering.

## Files Updated
- src/app/models/task.model.ts
- src/app/services/task.service.ts
- src/app/home/home.page.ts
- src/app/home/home.page.html

## How to Run the Project

1. Open the project folder.
2. Install dependencies if required:

   npm install

3. Start the development server:

   ionic serve

4. Open the URL displayed in the terminal.

## Learning Outcome
Learned how Angular Services and Dependency Injection help separate business logic from UI components. Practiced TypeScript interfaces, service-based task management, filtering and basic Observable concepts.
