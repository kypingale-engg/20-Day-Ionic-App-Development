# Day 1 – Introduction to Ionic App Development

## 1. Objective
To understand the Ionic framework and set up an Ionic Angular development environment.

## 2. Introduction to Ionic
Ionic is an open-source framework used to develop cross-platform mobile applications using web technologies like HTML, CSS and TypeScript.

## 3. Technologies Used
- Ionic Framework
- Angular
- TypeScript
- Node.js
- npm
- Capacitor

## 4. What is Angular?
Angular is a TypeScript-based web application framework used to build dynamic and interactive applications.

## 5. What is Capacitor?
Capacitor is a native runtime that allows web applications to run on Android and iOS devices.

## 6. What is Ionic CLI?
Ionic CLI is a command-line tool used to create, develop and manage Ionic applications.

## 7. Commands Practiced

- ionic start – Creates an Ionic project.
- ionic serve – Runs the application locally.
- ionic build – Builds the application.
- ionic capacitor add – Adds a native platform.
- node -v – Checks Node.js version.
- npm -v – Checks npm version.

## 8. Practical Work Completed
1. Created an Ionic Angular starter project.
2. Installed Capacitor CLI.
3. Installed Capacitor plugins.
4. Initialized Capacitor configuration.
5. Installed project dependencies.
6. Started the application using ionic serve.
7. Successfully opened the application in the browser.

## 9. Learning Outcome
Learned the basics of Ionic, Angular, Capacitor and the development environment setup process.
